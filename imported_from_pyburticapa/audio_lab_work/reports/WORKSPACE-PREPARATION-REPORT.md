## 5. Reproducibility concerns (unresolved)

1. **Python environment does not exist here, and no lockfile exists.** A new virtualenv is needed inside the working copy. The versions are recorded in `env\python-dist-info-from-venv.txt` (numpy 2.4.6, scipy 1.17.1, librosa 0.11.0, pydantic 2.14.1, pytest 9.1.1 and others). Resolution will be by version pin, not by lockfile.
   - **Hazard:** the live `.venv` points at the live `src`. If a later run uses that interpreter, `import audiolab` loads the **live** code. Any future run must set `PYTHONPATH` to the working copy's `src` and check `audiolab.__file__` first. Do not use `-I` for that check, because `-I` ignores `PYTHONPATH`.
2. **Node dependencies do not exist here.** `package.json` uses caret ranges and there is no lockfile, so a fresh install may resolve differently. Pin to the versions in `env\node_modules-installed-packages.txt`, or use `env\node_modules.package-lock.json`, when reinstalling. Esbuild, tailwindcss 3 and playwright-core are used but undeclared (Step 0 section 5).
3. **The preview `dist` in the working copy is the live development build**, not the compatibility baseline. It must be rebuilt in the working copy, using the minified commands, before any Squall comparison. The Step 0 snapshot's minified files (`4A273FE2…42B`, `C1115499…11EB`) remain the reference.
4. **Browser results are software-rendered** (`--disable-gpu`). Accretion frame-pacing evidence needs the new GPU-enabled launcher (Step 0 section 6.1).
5. **No Python lockfile, and `node_modules` history before 17:03 local is not recoverable** (recorded earlier; replaceable).
